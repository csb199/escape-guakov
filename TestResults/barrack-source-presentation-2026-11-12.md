# 原作整备室展示接入复核（2026-11-12）

本轮基于 Unity 6000.3.27f2 / D3D11。对应源码 SHA256 和新执行的检查见同名 JSON。验证命令：Tools/Test-BarrackEditor.ps1，结果 PASS；不沿用旧版构建报告，不代表 Player/AOT/热更发布验收。

## 已接入

- 原作 PC LutBuilderHdr、UberPost 原生 Shader，32 阶 HDR LUT、Unreal Filmic 分支、原 Volume 调色和暗角参数。旧宿主 Film 函数已删除。
- 原材质关键字与禁用 Pass 契约恢复；附加方向光纳入 per-object light index。源 _Light_Weapon 默认关闭，未为提亮画面擅自开启。
- 原作主面板/概览/公共控件的 554 节点、59 张图片、两份原始中文字体；公共模板图标/文本绑定；中文 HintData 本地化；四项有效 PC RectTransform 字段覆盖。字段枚举来自程序集元数据，不执行客户端代码。
- 原镜头 FOV、ScreenX/Y、旋转、自定义执行器的速度、范围、近景偏移、阻尼及往返时长。默认相机和头部近景之间的过渡有明确终点。
- 原 UI 返回按钮接入宿主返回流程；旧动作/效果面板仅 F8 打开。触摸、拖拽、两轮加载退出及加载中取消通过。

## 尚未完成的等价性

- 本轮原作窗口捕获持续超时；未拿到同机位原作截图，不能声称颜色已与原作一致。当前宿主图在 LocalOnly/Barrack/live/barrack-ui.png，原生 LUT 在 source-grading-lut.png。
- 原作运行时 Follow/LookAt 赋值未恢复。骨骼目标、动作到镜头的路由和防裁切 bounds guard 是宿主适配，尚非原作执行器逐分支移植。
- 动态角色账户字段、列表、顶部标签页及其余业务按钮尚未接通。模板占位文字被隐藏，未伪造账户数值；并非完整交互复刻。
- Bloom、AO、雾、平面反射合成和地面阴影接收仍含宿主实现；没有原作完整 TAA/运动向量链。
- 实际渲染像素差分证明阴影、AO、反射及后处理会影响输出，但不能证明与原作算法/画面等价。

下一次视觉校对需要原作默认整备室原始 PNG（带 UI）、隐藏 UI 的同机位图和画质设置图，避免有损压缩或系统显示滤镜影响判断。截图解决视觉参照缺口，原运行时逻辑的未恢复部分仍需继续追踪。
