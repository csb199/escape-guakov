# 闪电资源引用证据

- groza-name.json：原作本地化键 6246 对应“闪电”。
- groza-tables.json：角色、模型、动作路径和背景配置表的字段编号级解析；字段编号尚未全部映射为语义名称。默认模型配置 ID 1017 对应 GrozaSR01。
- ramps.json：原始贴图包中的渐变参数，含漫反射、高光、菲涅尔等配置；保留精确 PathID 字符串。保存参数不等于实现了原作 Shader。
- hair-render-contract.json：帧 8378 的头发模板投影、面部阴影和透明刘海绘制顺序、字节码哈希及 GPU 状态。相同字节码可能对应多个关键词组合，不从哈希反推唯一关键词。

本目录不是可运行角色、材质或后处理资产。更早检查的 GrozaR01 不作为默认 GrozaSR01 的替代。
